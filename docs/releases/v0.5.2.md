# 讯港 · NotiHarbor v0.5.2

本版统一消息中心，修复 Webhook 通知成功发送后在“消息”页面不可见的问题。

- `/message` 展示 Webhook、编辑器、旧推送接口及历史消息，支持搜索、筛选、分页与自动刷新。
- 消息详情统一展示正文、状态、各通道投递和发送尝试。投递日志作为消息中心内的独立标签，方便排查重试与发送失败。
- 移除重复的旧消息列表及其前端 SSE 连接。原网关历史、详情和日志链接自动跳转，并保留筛选参数；旧消息公开分享链接继续有效。
- 历史消息通过只读查询纳入列表，已关联到网关的消息去重展示，不迁移、不重发历史消息。历史归档仅供查看，不提供投递任务操作。
- 普通用户只能查看自己的消息及投递日志；应用 API Key 查询仍限定在所属应用内。

## 升级

镜像：`ghcr.io/jung233/notiharbor:v0.5.2`，支持 `linux/amd64` 和 `linux/arm64`。

将部署镜像标签改为 `v0.5.2`，拉取镜像后重新创建容器。保留现有数据库、数据目录和密钥，不需要数据库迁移或重新配置通道。

Compose 部署：

```bash
docker compose pull
docker compose up -d
```
