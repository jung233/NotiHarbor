# 讯港 · NotiHarbor v0.5.3

本版将 SMTP 邮件配置接入消息通道页面，可直接创建和编辑邮件推送通道。

- 通道类型中的「邮件」更名为「SMTP 邮件」，开放创建和保存。
- 支持独立配置 SMTP 服务器、端口、账号、密码／授权码、TLS／STARTTLS、发送超时、发件人和 HTML 正文。
- 连接信息全部留空时沿用系统 SMTP；编辑时密码不回显，留空保留原凭证。
- 兼容已有 `email` 类型通道，收件人和发信权限沿用现有规则。

## 升级

镜像：`ghcr.io/jung233/notiharbor:v0.5.3`，支持 `linux/amd64` 和 `linux/arm64`。

将部署镜像标签改为 `v0.5.3`，拉取镜像后重新创建容器。保留现有数据库、数据目录和密钥，无需数据库迁移。

在「通道 → 新建消息通道」中选择「SMTP 邮件」即可配置，详见 [SMTP 配置说明](../smtp-setup.md)。

## 验证

- 本地前端构建通过，修改文件的 ESLint 检查无错误。
- GitHub Actions 在发布前运行静态检查、前后端测试及 MySQL／Redis 集成测试，再构建双架构镜像。
- 实际邮件投递需要配置可用 SMTP 账号后验证。
